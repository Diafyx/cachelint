# cachelint 0.1.0a3

Third alpha release of the offline `cachelint` analyzer. Requires Python 3.11
through 3.14. The core package has no runtime dependencies.

## New in this release

- Opt-in `RequestRecorder` and `AsyncRequestRecorder` capture supported outbound
  SDK request bodies into local, analyzer-compatible JSONL. They use a dedicated
  SDK HTTP client and do not enable recording for other clients.
- Exact optional extras support `anthropic==1.8.0` Messages and
  `openai==3.37.0` Chat Completions. Both sync and async clients are exercised
  with synthetic requests and mock transports; recording makes no extra
  provider call.
- Status counters and fixed warning codes report skipped or failed captures
  without printing request content. Known credential-like JSON keys cause the
  entire attempt to be omitted. An SDK request still proceeds when capture
  fails after setup.

The offline ingestion, prefix comparison, and advisory length estimates from
the first two alphas remain available. After publication, install the exact
prerelease with `python -m pip install cachelint==0.1.0a3`. Recording needs an
extra, such as `python -m pip install 'cachelint[sdk-anthropic]==0.1.0a3'` or
`python -m pip install 'cachelint[sdk-openai]==0.1.0a3'`. See the
[recording guide](../recording.md) and [README](../../README.md).

## Limits and compatibility

Recording is supported only for the exact SDK versions and endpoints above,
using their default HTTPX2 clients. Other SDK versions, custom transports,
alternate base URLs, OpenAI Responses, and streaming bodies are outside this
alpha contract. One row represents an outbound attempt; retries may produce
duplicates, and a row does not prove delivery, response success, or a cache hit.
Close the recorder before analysis. A crash or write error can leave an
incomplete final JSONL line, which the analyzer rejects.

The log contains prompt and tool content. It is not a secret scanner: secrets
embedded in ordinary text can still be recorded. Choose a private directory,
keep recordings out of repositories and public issues, and set your own
retention policy. On POSIX, new files are owner-only. On Windows, the caller
must first restrict the parent directory ACL and explicitly acknowledge ACL
inheritance; cachelint does not verify that ACL.

The analyzer does not call a model provider. This is an alpha API; later
prereleases may change behavior with release notes. Within 0.x, patch releases
preserve documented CLI and Python API behavior; incompatible changes require
a minor release and migration notes.
