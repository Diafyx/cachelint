# cachelint 0.1.0a2

Second alpha release of the offline `cachelint` analyzer. Requires Python 3.11
through 3.14. The core package still has no runtime dependencies.

## New in this release

- `analyze` and `diff` show an advisory estimate for the modeled stable prompt
  prefix, using a dependency-free UTF-8 byte heuristic by default.
- The optional `tokenizer` extra enables `--estimate-method tiktoken` for OpenAI
  model IDs recognized by `tiktoken`. The count is based on cachelint's modeled
  content and does not include provider framing or hidden tokens.
- Exact model rules for Claude Sonnet 4.6, Claude Opus 4.6, and the listed GPT-5.6
  variants show a sourced minimum and review date. Other models show `unknown`.
- The Python `ComparisonResult.prefix_estimate` field exposes the advisory count,
  method, uncertainty, and optional minimum comparison without retaining prompt
  excerpts.

The `0.1.0a1` offline ingestion, comparison, and privacy behavior remains
available. Reports still locate the first modeled prefix divergence and separate
request context changes from prompt changes.

After publication, install the exact prerelease with
`python -m pip install cachelint==0.1.0a2`. To use the optional OpenAI tokenizer,
install `python -m pip install 'cachelint[tokenizer]==0.1.0a2'`. See the
[length estimate guide](../length-estimates.md) and [README](../../README.md).

## Limits and compatibility

Estimates count a diagnostic serialization, not provider-billed tokens. A
tokenizer-based count is still not provider-reported usage. Request bodies do not
contain response usage, and a threshold comparison cannot verify a cache hit.
Model rules were reviewed on 2026-10-25 against the linked provider sources;
provider policies may change. Unknown model eligibility stays unknown.

The analyzer does not call a model provider. Input files and Python canonical
request objects can contain sensitive prompts or credentials, so keep them
private. This is an alpha API; later prereleases may change behavior with
release notes. Within 0.x, patch releases preserve documented CLI and Python
API behavior; incompatible changes require a minor release and migration notes.
