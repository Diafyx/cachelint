# cachelint 0.1.0a1

First alpha release of the offline `cachelint` analyzer. Requires Python 3.11
through 3.14. The core package has no runtime dependencies.

## Included

- Read UTF-8 JSONL request bodies with `cachelint analyze`, or compare two JSON
  request files with `cachelint diff`.
- Accept Anthropic Messages and OpenAI Chat Completions request bodies, with an
  explicit provider option when auto-detection is ambiguous.
- Report the first difference in the modeled stable prompt prefix, a safe path
  and character offset when available, context changes, coverage warnings, and
  fixed findings without printing request values.
- Use the documented `canonicalize_request` and `compare_requests` Python APIs
  for offline analysis.

After publication, install the exact prerelease with
`python -m pip install cachelint==0.1.0a1`. Run `cachelint --help` for commands and
see the [README](../../README.md) for examples.

## Limits and compatibility

This release models a diagnostic prefix; it cannot confirm a provider cache
hit or reproduce private provider cache keys. Unsupported content and unknown
request context produce coverage warnings. Token counts and SDK recording are
planned for later milestones. The analyzer does not send request bodies to a
provider, but input files and Python canonical request objects may contain
sensitive prompts or credentials. Keep them private.

This is an alpha API. Later alpha versions can change behavior with release
notes. Within 0.x, patch releases preserve documented CLI and Python API
behavior; incompatible changes require a minor release and migration notes.
