# Security policy

Prompt and request logs may contain credentials or sensitive content. Do not put a vulnerability report, raw request log, token, or customer data in a public issue or PR.

Report vulnerabilities through [GitHub private vulnerability reporting](https://github.com/Diafyx/cachelint/security/advisories/new). If that link is unavailable, contact a repository maintainer privately before sharing technical details. The maintainer will enable and verify private reporting before a public release.

Supported versions will be listed after the first release. Until then, only the current development branch receives security fixes.
